# Taiwan Holiday CLI

台灣政府行政機關辦公日曆（國定假日、補班日）資料。

## 資料來源

政府資料開放平臺：[中華民國政府行政機關辦公日曆表](https://data.gov.tw/dataset/14718)。

## update.py

從 data.gov.tw 下載**今年與明年**的辦公日曆表，存成 `data/{西元年}.json`。

```bash
python3 update.py
```

- 只使用 Python 標準函式庫，不需安裝套件（需 Python 3.9+）。
- 流程：
  1. 呼叫 `https://data.gov.tw/api/v2/rest/dataset/14718` 取得資料集所有資源及其原始下載網址。
  2. 依民國年找出對應資源；若尚未發布（例如明年的日曆表通常在年中才公告）則顯示「略過」。
  3. 以原始下載網址的 MD5 組出 `quality.data.gov.tw/dq_download_json.php` 的 JSON 下載網址並下載。
  4. 檢查內容為非空陣列且第一筆日期屬於該年，通過後才覆寫 `data/{西元年}.json`。
- 任一年份下載或驗證失敗時，結束碼為 `1`；全部成功或僅有略過時為 `0`。
- `quality.data.gov.tw` 的憑證缺少 Subject Key Identifier，Python 3.13+ 預設的 X509 嚴格模式會拒絕連線，因此程式僅關閉嚴格模式，仍保留一般憑證鏈驗證。

## holiday.py

查詢放假日的 CLI，讀取 `data/` 內所有年份的資料（可跨年查詢）。

```bash
python3 holiday.py check [日期]   # 某天是否放假，預設今天；放假輸出 Y、上班輸出 N
python3 holiday.py check -v [日期] # 顯示完整內容，如「2026-10-10（六） 放假：國慶日」
python3 holiday.py next  [日期]   # 下一個國定假日
python3 holiday.py prev  [日期]   # 上一個國定假日
python3 holiday.py long  [日期]   # 下一個連假（連續放假 3 天以上）
python3 holiday.py workdays 起 迄  # 兩個日期之間的工作天數（含頭尾兩天）
python3 holiday.py add-workdays [日期] N  # 日期 + N 個工作天後的日期（N 可為負數）
```

- `workdays`、`add-workdays` 預設只輸出結果（天數或 `YYYY-MM-DD`），加 `-v` 顯示完整內容。
- 工作天 = `是否放假` 為 `"0"` 的日子（含補班日）。
- `add-workdays` 不含基準日本身，從隔天開始數，例如 `add-workdays 2026-10-12 20` → `2026-11-10`。

- 日期格式：`YYYY-MM-DD`、`YYYY/MM/DD`、`YYYYMMDD`，省略時為今天。
- 「國定假日」定義為放假且 `備註` 不為空的日子（含補假）；一般週末不算。
- `next`／`prev`／`long` 皆不含基準日當天；`long` 以連假的第一天在基準日之後為準。
- 查無資料時結束碼為 `1`。

```
$ python3 holiday.py long 2026-10-12
2026-10-24（六） ~ 2026-10-26（一），共 3 天（12 天後）
  2026-10-24（六）
  2026-10-25（日） 臺灣光復暨金門古寧頭大捷紀念日
  2026-10-26（一） 補假
```

## data

`data/{西元年}.json` 為該年每一天的陣列（共 365 或 366 筆），欄位沿用原始資料：

| 欄位 | 說明 | 範例 |
| --- | --- | --- |
| `西元日期` | `YYYYMMDD` 格式字串 | `"20260101"` |
| `星期` | 一～日 | `"四"` |
| `是否放假` | `"2"` 放假、`"0"` 上班（含補班日） | `"2"` |
| `備註` | 節日或調整說明，一般日子為空字串 | `"開國紀念日"` |

```json
[
  {
    "西元日期": "20260101",
    "星期": "四",
    "是否放假": "2",
    "備註": "開國紀念日"
  }
]
```

## 備註

週六、週日的 `是否放假` 也是 `"2"`，判斷是否為國定假日需搭配 `備註`。
